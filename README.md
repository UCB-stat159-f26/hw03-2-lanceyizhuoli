# tennisagegap

**Stat 159 HW3 — Collaborative and Reproducible Statistical Data Science (UC Berkeley, Fall 2026)**
Author: Lance (YiZhuo) Li

An R package that downloads a tennis player's career matches from
[Tennis Abstract](https://www.tennisabstract.com) and draws the New York Times
style scatter plot from HW2: the player's age on the x-axis, the age
difference with the opponent on the y-axis, and color for won/lost.

## Usage

```r
library(tennisagegap)

# Serena Williams data and plot
serena <- get_career_matches("serena williams")
plot_career_matches(serena)

# Rafael Nadal data and plot
rafa <- get_career_matches("Rafael Nadal")
plot_career_matches(rafa)

# returns a meaningful error message
unknown_player <- get_career_matches("GastonSanchez")
#> Error: No Tennis Abstract career data found for "GastonSanchez"
#> (tried https://www.tennisabstract.com/jsmatches/GastonSanchezCareer.js).
#> Check the spelling, e.g. "Serena Williams" or "RafaelNadal".
```

## Public functions

| Function | Input | Output |
|---|---|---|
| `get_career_matches(player_name)` | Player name in any of the forms `"serena williams"`, `"Serena Williams"`, `"SerenaWilliams"` | Data frame, one row per completed match |
| `plot_career_matches(matches)` | Data frame from `get_career_matches()` | `ggplot` scatter plot |

### Columns returned by `get_career_matches()`

| Column | Type | Description |
|---|---|---|
| `player` | character | Player's name, e.g. `"Serena Williams"` |
| `date` | Date | Match date |
| `tournament`, `surface`, `level`, `round` | character | As recorded by Tennis Abstract |
| `opponent` | character | Opponent's name |
| `player_age` | numeric (years) | (match date − player's date of birth) / 365.25 |
| `opp_age` | numeric (years) | Female files: (match date − opponent's DOB) / 365.25. Male files: age as listed |
| `age_diff` | numeric (years) | `player_age − opp_age`; positive = player is older |
| `result` | factor | `won` or `lost` |

Matches without a `W`/`L` result or without an opponent age are dropped.

## How it works

1. The name is converted to Tennis Abstract's id (`"serena williams"` → `SerenaWilliams`).
2. `jsmatches/<id>Career.js` is downloaded. If it does not exist, the function stops with an error.
3. The JavaScript match array is parsed as JSON. Field 17 of each match holds the
   opponent's **date of birth** in female players' files and the opponent's **age**
   in male players' files; the package tells them apart by the format (8-digit date vs. number).
4. The player's own date of birth (`var dob = ...`) is read from the career file or,
   if it is not there, from the player's Tennis Abstract page.

## Tests

```r
devtools::test()
```

The tests never contact tennisabstract.com. They run on mock-up career files in
`tests/testthat/fixtures/` (`FemalePlayerCareer.js`, `MalePlayerCareer.js`), and
`get_career_matches()` is tested with the downloader `read_remote()` replaced by a
fake via `testthat::local_mocked_bindings()`.
